Antes de empezar

Cómo se lee esta guía

El otro sistema le manda a TIZADA PRO un pedido: qué prendas, con qué diseño, en qué tela y la lista de personas (la planilla). TIZADA arma la tizada: los archivos que se imprimen para fabricar todo. Cada tema de esta guía tiene dos partes:

En simple

Para el que vende o atiende al cliente: qué es, para qué sirve y cuándo elegirlo. Sin nada técnico.

Para el programador

El campo exacto del pedido.json, con un ejemplo listo para copiar.

La regla de oro

Todo lo que se elige en la pantalla de TIZADA al armar un pedido a mano, el otro sistema lo manda como un dato del pedido. Si un dato no viene, TIZADA usa lo que tiene configurado ese molde.

El pedido en una mirada
{
  "formato": "tizadapro.pedido/1",
  "referencia": "OV-2026-00123",

  "disenos": [ { "nombre": "JUGADOR", "moldes": [ { "variable": "v_bu8p7gy", "tela": "232", "arte": "artes/jugador.ai" } ] } ],

Lo más importante

La columna cantidad tiene dos usos

El mismo número significa cosas distintas según cómo se pidan las mesas. Hay que elegir uno de los dos en cada pedido.

Uso 1 · cantidad de prendas

"mesas": {"modo": "normal"}
  • 3 = 3 prendas iguales. TIZADA repite la fila.
  • Todas las filas se mezclan en las mesas para gastar la menor tela.
  • Es el uso normal: si no sabés cuál elegir, es éste.

Uso 2 · copias de la mesa

"mesas": {"modo": "una_por_fila"}
  • 3 = la fila se arma una vez en su propia mesa, y esa mesa se imprime 3 veces.
  • Si las copias llenan una mesa del largo máximo, esa mesa sale una vez marcada ×N; lo que no llena una mesa va junto con el resto del pedido (talles mezclados), ×1.
  • Necesita que la planilla tenga columna de cantidad.

La cantidad · cuándo y cómo

Cuál elegir y cómo se manda

En simple

Usá el 1 (prendas) en los pedidos de equipo y en todo lo que lleve nombre o número: cada persona es una fila y la cantidad es cuántas prendas iguales lleva. TIZADA junta todo para gastar la menor tela.

Usá el 2 (copias) cuando algo se fabrica muchas veces igual y conviene imprimir la misma mesa repetida: banderas o banderines iguales, prendas sin nombre ni número, muestras, o cuando el taller necesita cada fila separada para cortar o entregar.

Para el cliente se puede preguntar así: «¿Cantidad de prendas (se mezclan para ahorrar tela)?» o «¿Copias de esta mesa (cada fila aparte)?».

No usar el 2 con nombres distintos

Si cada prenda lleva su nombre, cada fila tiene cantidad 1 y el uso 2 sólo agrega mesas y gasta más tela.

Para el programador · uso 1 (prendas)
"mesas": { "modo": "normal" },          // o no mandar "mesas"
"planilla": [
  { "diseno": "JUGADOR", "talle": "M", "nombre": "PÉREZ", "numero": "10", "cantidad": "1" },
  { "diseno": "JUGADOR", "talle": "S", "nombre": "",      "numero": "",   "cantidad": "15" }
]                                            // = 16 camisetas, mezcladas
Para el programador · uso 2 (copias de la mesa)
"mesas": { "modo": "una_por_fila" },
"planilla": [
  { "diseno": "BANDERA CLUB",    "cantidad": "20" },
  { "diseno": "BANDERA SPONSOR", "cantidad": "5" }
]
// en el resultado, cada archivo de tizada trae su fila y sus copias:
{ "tipo": "tizada", "nombre": "OV-123__Mesa 1 - Bandera (1,60) - Fila 1 - x20.pdf",
  "mesa": 1, "fila": 1, "copias": 10, "por_mesa": 2, "ancho_cm": 157.0, "largo_cm": [312.4] }

Qué tiene que hacer su sistema: guardar fila, copias y por_mesa de cada archivo y mandarlo a imprimir copias veces; cada impresión trae por_mesa unidades (unidades = por_mesa × copias).

Sólo la mesa llena va aparte; lo demás va junto: las filas con la misma pieza (mismo molde y talle) que llenan una mesa salen en mesas que se repiten (JUGADOR 33 + GOLERO 34 → 4+4 ×8); lo que no llena una mesa, de cualquier fila y talle, va junto ×1. Separar talles es mesas.modo = "por_talles". Esos archivos traen "fila": null y "filas": [{"fila": 1, "por_mesa": 4}, …]. Para cada diseño aparte: mesas.separar_disenos: true (el archivo trae diseno).

ReglaQué pasa

Cómo se reparten las mesas

Talles por mesa

En simple

Para que ciertos talles salgan juntos en una mesa y separados del resto, por ejemplo para cortar o entregar por talle. La cantidad sigue siendo de prendas (como en el uso 1).

Para el programador
"mesas": { "modo": "por_talles", "grupos": [["S", "M"], ["L", "XL"]] }
// un talle por mesa: [["S"], ["M"], ["L"]] · los talles que no están en ningún grupo van juntos al final
// en el resultado: "talles": ["S","M"] y el nombre "OV-123__Mesa 1 - Tela - Talles S-M.pdf"
// MISMA MESA SIN MEZCLAR: "mesas": { "modo": "talles_separados" } → cada talle aparte, apilados con
// una línea punteada entre talles; "grupos" opcional (ésos sí van juntos); resultado "separados": true
// LARGO MÁXIMO DE CADA MESA (botón «Largo»): "mesas": { "modo": "normal", "largo_max_m": 12.5 }
// sin él rige el del nesting del molde; de 0,10 a 50 m (si no → largo-mesa-invalido)
// SEPARAR DISEÑOS (botón «Separar»): "mesas": { "separar_disenos": true } → cada diseño en sus mesas
// (por defecto el MISMO MOLDE se mezcla aunque cambie el diseño); cada archivo trae "diseno"

Los talles se escriben como los tiene el molde (GET /variables). Uno que no existe → mesas-invalido. El largo máximo vale con cualquier modo: ninguna mesa lo pasa y lo que no entra sigue en otra.

Qué se fabrica

Diseños, prendas y planilla

En simple

Un pedido puede tener varios diseños (jugador, golero, visitante…). Cada diseño dice qué prendas lleva y con qué arte. La planilla es la lista de personas: cada fila dice de qué diseño es, el talle, el nombre y el número a estampar y opciones como la manga.

DatoCómo se manda
Los diseñosdisenos[].nombre; en cada fila, diseno (con un solo diseño se puede omitir)
La prendadisenos[].moldes[].variable: la clave v_… de GET /variables. Una por prenda en cada diseño
El artearte (.ai/.pdf) en el molde o una vez en el diseño, hecho sobre la plantilla (POST /plantillas)
TalleComo lo tiene el molde (M, 2XL). Cada molde lee su columna de talle. Planilla sin talles: no va

Lo mismo que hace el operario con el arte

En simple

Todo lo que el operario puede hacer en el pedido, el otro sistema también lo puede mandar: mover, girar o agrandar un objeto del diseño, cambiarle el color, decir qué parte del arte va en cada pieza, cambiar una tipografía por otra o pedir que un objeto no se imprima.

En la pantallaEn el pedido (en el molde)
Mover, rotar, escalar o espejar un objeto"ajustes": {"escudo": {"dx": 0.05, "rot": 15, "scale": 1.2}} (+ talles opcional)
Cambiarle el color"colores": {"escudo": {"fill": [0, 1, 1, 0]}} (CMYK de 0 a 1)
Qué mesa del arte va en cada pieza"mapeo_arte": {"Frente": 1} (número o rótulo de la mesa)
Cambiar una tipografía del arte"reemplazos": {"FuenteDelArte": "Anton Regular"}
Que un objeto no se imprima (ni la cruz)"editables": {"sponsor": "no_imprimir"}
El perfil de coloropciones.perfil_color, uno de GET /perfiles

Con qué y cómo

Tela, piezas y lo que no se sublima

La tela

En simple

Cada prenda tiene una tela principal. Si alguna pieza va en otra (por ejemplo el cuello en rib), se dice cuál.

Para el programador
"tela": "232",                                  // obligatorio: el id de GET /telas
"telas_por_pieza": { "Cuello": "486" }            // la pieza por su nombre sin número

Piezas que no se hacen

En simple

Para fabricar la prenda sin alguna pieza en todo el pedido (por ejemplo, sin tapa costura).

Para el programador
"piezas_apagadas": ["Tapa costura"]        // no se pueden apagar todas

Escudo, logo y sponsor: lo que no se sublima

En simple

Si el escudo va bordado o el logo en TPU o DTF, no se imprime con el diseño: en su lugar va una cruz que marca dónde aplicarlo, y la ficha técnica dice qué poner y dónde.

Para el programador
"editables": {
  "escudo":  "sublimado",                       // se imprime (es lo que pasa si no se nombra)
  "logo":    "tpu",                             // "tpu" · "bordado" · "dtf": no se imprime, va la cruz
  "sponsor": { "proceso": "bordado", "cruz": false }  // sin la cruz en la tela (sólo en la ficha)
}

El nombre es el de la capa del arte sin «Editable» (Editable escudo → escudo).

Banderas y por si algo falla

Piezas a medida y opciones

Banderas y piezas a medida

En simple

Las banderas no tienen talle: se piden con su medida del diseño en metros, su forma (rectángulo, círculo o triángulo), cómo se termina el borde y, si llevan, las tiras para coser. TIZADA le suma el margen y la gira si así entra en la tela.

CampoQué poner
medida{"ancho_m": 3, "alto_m": 1.5} — del diseño. Círculo: {"diametro_m": 1.2}
formarectangulo (si no viene) · circulo · triangulo
orientacionSólo triángulo, hacia dónde va la punta: abajo · arriba · izq · der
terminaciondobladillo · overlock · sin
tiras{"lleva": true, "lados": {"arriba": 5, "abajo": 5}} (cada número cuenta las 2 puntas). Triángulo: {"base": 5, "laterales": 4}; círculo: {"alrededor": 12}
Antes de confirmar

POST /a_medida/calcular dice el total, en qué telas entra (girada si hace falta) y cómo salen las tiras. El arte se arma sobre la plantilla de esa medida (POST /plantillas).

COMO APLICAR ESTA ACTUALIZACION (TIZADA PRO)
============================================

1. Detener el servidor (cerrar la ventana donde corre "py servidor.py").

2. Extraer TODO este ZIP sobre la carpeta donde esta instalado el sistema,
   eligiendo SOBREESCRIBIR cuando pregunte.

   Es seguro: el ZIP trae solo el CODIGO. Los datos del cliente (carpetas
   datos/, entrada/, trabajos/ y el archivo config_externo.json) no vienen
   en el ZIP, asi que quedan exactamente como estaban.

3. Volver a iniciar el servidor: iniciar.bat (o "py servidor.py").

La pantalla ya viene compilada adentro (frontend/dist): NO hace falta
node ni npm en el servidor.

Que cambio en cada version: ver el CHANGELOG al final de MAPA_DEL_SISTEMA.md.

--------------------------------------------------------------
PARA NO RECIBIR MAS ZIPS (recomendado, se hace UNA sola vez)
--------------------------------------------------------------
Si instalas el sistema por git, las proximas actualizaciones son un doble
clic en el servidor (ACTUALIZAR-SISTEMA.bat) y no hace falta mandar nada:

  1. En una carpeta NUEVA del servidor, correr INSTALAR-EN-OTRA-PC.bat
     (instala lo necesario y baja el sistema; pide una cuenta de GitHub
     con acceso al repositorio).
  2. Copiar de la carpeta vieja a la nueva: datos\, entrada\, trabajos\
     y config_externo.json.
  3. Arrancar desde la carpeta nueva (iniciar.bat).

Desde ahi, actualizar = doble clic a ACTUALIZAR-SISTEMA.bat + reiniciar.
